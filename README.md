# Мои дела

Личный планер: входящие, проекты, календарь, план дня, приоритеты, шаги, комментарии, повторы и оценка времени. Сайт: https://nesmiyan-polina.github.io/moi-dela/

Стрелка у строки добавляет дело быстро. Кнопка «Создать с подробностями» открывает полную форму до сохранения: в ней можно сразу указать срок, проект, важность, шаги и комментарий. Нажатие на дело открывает его редактирование. На телефоне разделы и проекты находятся в меню ☰ слева.

## Телефон и офлайн

Откройте сайт на телефоне с интернетом, войдите в аккаунт и добавьте его на главный экран. На Android в Chrome: меню ⋮ → «Установить приложение» или «Добавить на главный экран». На iPhone в Safari: «Поделиться» → «На экран Домой».

После первого открытия файлы планера сохраняются на устройстве. Firestore хранит просмотренные дела и изменения локально; после возвращения сети они синхронизируются с облаком. Для первого входа интернет необходим. Офлайн-копия остаётся на устройстве, поэтому используйте планер на личном телефоне или компьютере.

Время напоминания сохраняется и синхронизируется, но пока напоминает только в открытом планере. Push при полностью закрытом приложении требует серверной отправки; текущий проект работает на бесплатном Firebase Spark без Cloud Functions. Не считать это фоновым уведомлением.

## Данные и доступ

Firebase Authentication использует почту и пароль. Firestore хранит задачи в `users/{uid}/tasks`, шаги и комментарии в подколлекциях каждой задачи, пользовательские проекты в `users/{uid}/projects`, настройку доступного времени в `users/{uid}/settings/planning`. Правила из `firestore.rules` ограничивают доступ владельцем аккаунта и проверяют формат записей. Это прототип правил; перед широким распространением их нужно дополнительно проверить.

Старые задачи с названиями стандартных проектов «ВЦ», «Эко», «Личное» отображаются в новых проектах. Переименование проекта не меняет идентификатор, поэтому существующие задачи сохраняют связь с ним.

Для локальной проверки: `python -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/`. Если Firebase недоступен, приложение не переключается автоматически в локальный предпросмотр, чтобы не создать две несвязанные копии задач.
