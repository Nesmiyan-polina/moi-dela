# Мои дела

Личный планер с быстрым добавлением задач, сроками, проектами и разделами «Сегодня», «Ближайшие», «Без даты». Дизайн основан на выбранном светлом макете с тёмно-зелёным акцентом.

## Текущее состояние

Конфигурация веб-приложения Firebase уже добавлена. Email/Password включён, база Cloud Firestore создана, а правила из `firestore.rules` пользователь опубликовал в Firebase Console. До публикации сайта и проверки входа синхронизация считается непроверенной. Дела из прежнего локального предпросмотра автоматически в облако не переносятся.

## Подключение синхронизации

1. Опубликовать содержимое этой папки через GitHub Pages репозитория `Nesmiyan-polina/moi-dela`. `index.html` должен находиться в корне ветки `main`.
2. Если Firebase потребует, добавить домен сайта в Authorized domains в Authentication.
3. На сайте создать аккаунт, добавить тестовое дело и проверить появление записи в Firestore. Войти с той же почтой на другом устройстве и проверить синхронизацию.
4. Проверить правила доступа в Firestore Rules Playground или эмуляторе: чужой UID не может читать и менять задачи другого пользователя.

До выполнения шагов 1–4 не считать планер проверенным для синхронизации. Не использовать тестовый режим правил Firestore: данные задач должны быть доступны только владельцу аккаунта.

Для локальной проверки: `python -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/`.
