# Мои дела

Личный планер с быстрым добавлением задач, сроками, проектами и разделами «Сегодня», «Ближайшие», «Без даты». Дизайн основан на выбранном светлом макете с тёмно-зелёным акцентом.

Сайт: https://nesmiyan-polina.github.io/moi-dela/

## Текущее состояние

Конфигурация веб-приложения Firebase уже добавлена. Email/Password включён, база Cloud Firestore создана, а правила из `firestore.rules` пользователь опубликовал в Firebase Console. Сайт опубликован, и экран входа загрузился в браузерной проверке. Сохранение дела и синхронизацию нужно проверить после первого входа. Дела из прежнего локального предпросмотра автоматически в облако не переносятся.

## Подключение синхронизации

1. Если Firebase потребует, добавить домен сайта в Authorized domains в Authentication.
2. На сайте создать аккаунт, добавить тестовое дело и проверить появление записи в Firestore. Войти с той же почтой на другом устройстве и проверить синхронизацию.
3. Проверить правила доступа в Firestore Rules Playground или эмуляторе: чужой UID не может читать и менять задачи другого пользователя.

До выполнения шагов 1–3 не считать планер проверенным для синхронизации. Не использовать тестовый режим правил Firestore: данные задач должны быть доступны только владельцу аккаунта.

Для локальной проверки: `python -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/`.
